## UI Context

### Design tokens

Tailwind 4 (`tailwindcss: ^4`, `package.json`). `app/globals.css`:

- shadcn oklch semantic set — `@theme inline` maps `--color-*` onto `--*` in `:root` + `.dark`.
- landing accents (`@theme`): `--color-brand`, `--color-brand-deep`, `--color-brand-veil`, `--color-ink`, `--color-ink-soft`, `--color-paper`, `--color-paper-deep`.
- spacing + type scale: Tailwind defaults; marquee/perspective classes at `globals.css:157`, `:223`.

Utilities actually generated by `globals.css` (not the non-existent `bg-surface`/`text-text-primary`):

- layers: `bg-background`, `bg-card`, `bg-secondary`, `bg-muted`
- text: `text-foreground`, `text-muted-foreground`, `text-card-foreground`
- borders: `border`, `border-dashed` (`*` gets `border-border` in base)
- radius: `rounded-md|lg|xl|2xl|3xl`
- elevation: `shadow-sm|none|2xl`
- landing: `bg-brand-veil`, `text-brand-deep`, `bg-ink`, `text-paper` — no `#hex` in markup
- exception: `next/og` renderers (`lib/brand-mark.tsx`, `lib/og-card.tsx`) inline hex in `style`. Satori resolves no stylesheet and supports no Tailwind, so those two files cannot use utilities or tokens.

### Per-component conventions

- Server Component default. Client only for form interactivity/state/realtime. `components/hero.tsx` + `components/landing-flow.tsx` are client only to read scroll for `motion`; `app/page.tsx` bento/category/CTA stay server.
- Props annotated only where `tsc` demanded. Inferred props remain in `budget-progress.tsx`, `transaction-table.tsx`, `transaction/_components/*` forms; rows through `serializeTransaction` are `any` — shape mismatch there is not compiled.
- Handlers: `onChange` / `onSubmit` / `onDelete`. Form state: RHF + Zod; submit = server action.
- `Select` (`components/ui/select.tsx`, wraps `@base-ui/react`): closed trigger can't read a `SelectItem` label (items unmount until popup opens). When value is an id, pass `items` (`{label,value}[]`) or the trigger shows the raw id. Control with `value={x ?? null}`, never `undefined` (undefined = uncontrolled, warns mid-life; also why `defaultValue` can't carry a post-mount value like a receipt scan).

### Styling rules

- Use Tailwind utilities, not raw `style={}` / hardcoded colors / `#hex` / `px-[123px]` / magic numbers.
- One exception: a `motion` element may bind `MotionValues` via `style` (library's only transform channel). Values come from `useScroll`/`useTransform`, never literals.
- Reveals animate `y`/`rotateX`/`scale`, never `opacity` — server emits `initial`, and `opacity: 0` ships copy invisible to a non-hydrating client.
- `prefers-reduced-motion` stops the marquee (CSS) and scroll-linked transforms (`useReducedMotion`).
- Dialog/dropdown/tooltip state: use `components/ui/*` (Base UI wrappers). No `@radix-ui`.

### Images / assets

- `next/image` required. Remote: `randomuser.me`; formats AVIF/WebP (`next.config.ts`).
- Icons: `lucide-react@^1.57.0`. No committed SVG; generate from the library.
